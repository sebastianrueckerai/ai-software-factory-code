## Rulings

Rulings are per-plan bookkeeping in the gitignored ledgers under `.superpowers/sdd/<plan>/`; no clone can open them, so a number or a path in a tracked file or a commit message points at a book no reader can open. No ruling number and no ledger path appears in either: a document that needs a decision states the decision. `.githooks/pre-commit` refuses violations.
