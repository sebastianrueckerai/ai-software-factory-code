Projects

Each project is a repository the factory works on, the namespaces it deploys into, and its settings. The project owns its CI/CD; the factory owns the gates, these settings and the hardware limits. The settings are the project's file in the configuration: change them in Git. New project files a new project's file as a pull request and shows each step up to its board: the merge, the Forgejo organisation, repository, CI user and tokens made with the Forgejo admin's login, and the rest registration sets up.
