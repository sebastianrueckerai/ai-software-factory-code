# pg export derivation (card factoryd-export-prep)

Derived by the scratch trial-move compile loop the card prescribes:
the 28 *_pg_test.go files copied to internal/factoryd/pgtrial as
`package pg` with `import . "…/internal/factoryd"`, plus the test-file
helper declarations the group reaches (copied as decls into the scratch,
110 names), compiled with -gcflags=all=-e until the only
remaining errors name the exports below. Stable across repeated passes;
no unclassified error lines. Regenerate: copy pg files as package pg with
the dot import, add the helper decls the errors name from non-pg test
files, iterate. faceStop is a method on Runner declared in
face_stop_test.go: exporting it requires moving its decl into a non-test
file (methods are invisible to package pg from test files).
