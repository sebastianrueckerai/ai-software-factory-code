# Every image and chart the factory uses and does not build (roadmaps 203
# and 242), one per line: an image's or OCI chart's upstream name and tag,
# pinned by its linux/amd64 digest, or a file's URL, pinned by its sha256
# and followed by what the store makes of it. scripts/upstream-copy fills
# the factory's store, org upstream of git.aisoftwarefactory.world, from
# them, and CI's upstream job runs it on every push to main. Every
# reference names the copy, git.aisoftwarefactory.world/upstream/<the
# line>, or for a chart archive the store's Helm repository and for a
# file a pod needs the image that carries it: this
# repository's Dockerfiles and workflows, and the infra repository's
# manifests, HelmReleases and their sources, and its runner's job image. A
# line marked bootstrap is referenced at its upstream: Forgejo serves the
# store, so what Forgejo, its database and the cluster's start run on
# cannot depend on it, and a project's own manifests are the project's;
# the nodes' registry mirror serves these from the store while it answers,
# from their upstreams when it does not. An image's
# copy is tagged twice: its tag and the digest's first 12 hex digits, which
# never moves, and its upstream tag, which names the pinned digest for a
# pull by tag through the mirror. The weekly upstream card bumps these
# lines.
